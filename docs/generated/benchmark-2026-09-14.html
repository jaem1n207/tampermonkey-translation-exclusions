합성 DOM 회귀·성능 검증 스냅샷

원본 v0.2와 확장된 스크립트(596a3f7)의 스냅샷입니다. 설치 파일은 저장소의 GitHub Pages에서 받으세요. 브라우저에서 실행하면 동작 검사 16개와 합성 DOM 벤치마크를 다시 수행합니다. 외부 연결이나 추가 설치는 필요 없습니다.

실제 DOM·MutationObserver를 사용합니다. 프레임과 타이머의 대기 시간은 제어된 큐로 대체합니다. 아래 CPU 시간은 대기 시간·테스트 DOM 생성·결과 검사를 제외한 스크립트 실행 구간의 합입니다. 각 구조에서 예열 2회 후 측정 9회의 중앙값을 비교합니다. 웹페이지 전체 성능이나 실제 번역기·에디터 호환성을 측정하지 않습니다.
